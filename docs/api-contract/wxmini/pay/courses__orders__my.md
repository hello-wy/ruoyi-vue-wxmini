# GET /wxmini/pay/courses/orders/my

## 用途

查询当前小程序用户课程报名订单。

## 鉴权

- `Wx-Authorization: Bearer <token>`

## 成功响应字段

- `orderNo`
- `courseId`
- `courseName`
- `name`
- `gender`
- `phone`
- `company`
- `accommodation`
- `enrollmentId`
- `amount`
- `status`
- `payTime`
- `signTime`
- `refundTime`
- `createTime`
